# Bulico Brand / 品牌资产

Simple vector marks for **Bulico — Revit 2026.5+ plugin collection**.

**Selected direction:** the refined **Grid Stack** mark (`01-grid-stack.svg`), with dark, monochrome, app-icon and lockup variants.

## Files / 文件

| File | Concept | Suggested use |
|------|---------|---------------|
| `01-grid-stack.svg` | Grid Stack 主标志（精修）/ refined primary | 首选主标志、浅色背景 |
| `01-grid-stack-dark.svg` | Grid Stack 深色版 / dark variant | 深色背景、夜间界面 |
| `01-grid-stack-mono.svg` | Grid Stack 单色版 / monochrome | 单色印刷、雕刻、小尺寸 |
| `app-icon-grid-stack.svg` | Grid Stack App 图标 / app icon | Revit 面板、Windows 图标 |
| `bulico-lockup.svg` | Grid Stack 横向组合标志 / horizontal lockup | README、网站、演示文稿 |
| `02-b-monogram.svg` | 几何 B 字母 / geometric B monogram | 备选图标、头像、社交平台 |
| `03-floor-plan.svg` | 平面网格与核心筒 / floor-plan module | 按钮、工具栏、小尺寸 |
| `04-mullion.svg` | 幕墙横挺 / curtain-wall mullion | 幕墙相关功能、分区标识 |
| `05-module.svg` | 四宫格模块 / modular grid | 功能集合、插件面板 |
| `app-icon.svg` | B 字母 App 图标（备选）/ alternate app icon | 备选图标 |

| Teal | `#14B8A6` | 强调色、节点、选中状态 |
| Paper | `#F8FAFC` | 浅色背景、深色背景上的反白 |

## Usage notes / 使用说明

- 所有独立标志为 `512 × 512` 画布，四周至少保留约 `72 px` 安全区。
- Grid Stack 采用圆角等轴测楼板，顶部为实心 Teal，无核心筒开孔；整体高度已压缩。深色与单色版本使用同一套几何，可直接替换使用。
- 其余标志的主线条使用 `currentColor`，嵌入 HTML 时可通过 CSS `color` 切换深浅；青色强调固定为 `#14B8A6`。
- `app-icon-grid-stack.svg` 与 `app-icon.svg` 已包含深色圆角底板，可直接导出 512 / 256 / 128 px PNG。
- `bulico-lockup.svg` 的文字使用系统无衬线字体（Segoe UI / Inter / Helvetica / Arial）；正式印刷或长期使用前建议转为轮廓。
- 预览：直接在浏览器打开 `preview.html`。
