# Bulico Brand / 品牌资产

Simple vector marks for **Bulico — Revit 2026.5+ plugin collection**.

## Files / 文件

| File | Concept | Suggested use |
|------|---------|---------------|
| `01-grid-stack.svg` | 等轴测楼层堆叠 / isometric floor stack | 主标志、深色背景、技术文档 |
| `02-b-monogram.svg` | 几何 B 字母 / geometric B monogram | App 图标、头像、社交平台 |
| `03-floor-plan.svg` | 平面网格与核心筒 / floor-plan module | 按钮、工具栏、小尺寸 |
| `04-mullion.svg` | 幕墙横挺 / curtain-wall mullion | 幕墙相关功能、分区标识 |
| `05-module.svg` | 四宫格模块 / modular grid | 功能集合、插件面板 |
| `bulico-lockup.svg` | 横向组合标志 / horizontal lockup | README、网站、演示文稿 |
| `app-icon.svg` | 深色圆角 App 图标 / app icon | Windows / Revit 图标、商店图标 |
| `preview.html` | 方案预览 / contact sheet | 浏览器中查看全部方案 |

## Palette / 品牌色

| Name | Hex | Usage |
|------|-----|-------|
| Ink | `#0B1727` | 主线条、文字 |
| Teal | `#14B8A6` | 强调色、节点、选中状态 |
| Paper | `#F8FAFC` | 浅色背景、深色背景上的反白 |

## Usage notes / 使用说明

- 所有独立标志为 `512 × 512` 画布，四周保留约 `96 px` 安全区。
- 主线条使用 `currentColor`，嵌入 HTML 时可通过 CSS `color` 切换深浅；青色强调固定为 `#14B8A6`。
- 深色背景请内联 SVG 后设置 `color: #F8FAFC`，或复制文件并替换 `color` 属性。
- `app-icon.svg` 已包含深色圆角底板，可直接导出 512 / 256 / 128 px PNG。
- `bulico-lockup.svg` 的文字使用系统无衬线字体（Segoe UI / Inter / Helvetica / Arial）；正式印刷或长期使用前建议转为轮廓。
- 预览：直接在浏览器打开 `preview.html`。
