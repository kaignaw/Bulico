# Bulico Brand / 品牌资产

> 所属：[Bulico Visual Identity](../README.md)

Simple vector marks for **Bulico — Revit 2026.5+ plugin collection**.

**Selected direction:** the refined **Grid Stack** mark (`01-grid-stack.svg`), with dark, monochrome, app-icon and lockup variants.

## Files / 文件

| File | Concept | Suggested use |
|------|---------|---------------|
| `01-grid-stack.svg` | Grid Stack 主标志（精修）/ refined primary | 首选主标志、浅色背景 |
| `01-grid-stack-dark.svg` | Grid Stack 深色版 / dark variant | 深色背景、夜间界面 |
| `01-grid-stack-mono.svg` | Grid Stack 单色版 / monochrome | 单色印刷、雕刻、小尺寸 |
| `app-icon-grid-stack.svg` | Grid Stack App 图标 / app icon | Revit 面板、Windows 图标 |
| `bulico-lockup.svg` | Grid Stack 横向组合标志 / horizontal lockup | README、网站、演示文稿（浅色） |
| `bulico-lockup-dark.svg` | Grid Stack 横向组合标志（深色）/ dark lockup | README 深色主题、深色背景 |
| `preview.html` | Grid Stack 方案预览 / brand preview | 浏览器中查看全部品牌资产 |

## Palette / 品牌色

| Name | Hex | Usage |
|------|-----|-------|
| Ink | `#0B1727` | 主线条、文字 |
| Teal | `#14B8A6` | 强调色、节点、选中状态 |
| Paper | `#F8FAFC` | 浅色背景、深色背景上的反白 |

## Usage notes / 使用说明

- 所有独立标志为 `512 × 512` 画布，四周至少保留约 `72 px` 安全区。
- Grid Stack 采用圆角等轴测楼板，顶部为实心 Teal，无核心筒开孔；整体高度已压缩。顶部无边线、下方两层有描边，因此中层与底层整体上移 10px 补偿描边外扩，使三条可见间距一致。深色与单色版本使用同一套几何，可直接替换使用。
- `app-icon-grid-stack.svg` 已包含深色圆角底板，可直接导出 512 / 256 / 128 px PNG。
- `bulico-lockup.svg` 与 `bulico-lockup-dark.svg` 的文字使用系统无衬线字体（Segoe UI / Inter / Helvetica / Arial）；正式印刷或长期使用前建议转为轮廓。
- 命令图标位于 `Brand/Icons/`，沿用 Ink + Teal 系统，包含 SVG 源文件与 32/16 px PNG。
- 预览：直接在浏览器打开 `preview.html`。
